What every version below fixes
Menu = actions. Status is one line. Counters, backend, transport and last error move to a Diagnostics section in Settings (with a Copy button for bug reports).
Add phone… is a button. It's in the menu and in Settings, and opens the QR dialog. No terminal needed. Try it on any slide.
No dead fields. Disabled boxes saying “not used” or “not needed” are hidden instead.
Phones are visible. Paired phones are listed with their state and a Remove button.
One window, one save model. Settings apply instantly. Only changes to the connection itself ask for a restart.
